# Security policy

Vonar is a free VST3 synthesizer for Windows. Official downloads are only available from
https://xami-sound.pages.dev and the GitHub releases of this repository
(https://github.com/itsXami/vonar/releases). Any other site is unofficial.

## Reporting a vulnerability

Please report security problems privately through GitHub's private vulnerability reporting:
https://github.com/itsXami/vonar/security/advisories/new

Do not open a public issue for a security problem. Reports are welcome in English or Polish.

## What to report

- a problem in the plugin or installer that could harm a user's computer or projects,
- a release file whose SHA-256 does not match the one published on https://xami-sound.pages.dev,
- a site or file that pretends to be the official Vonar download.

## Supported versions

Only the latest release receives fixes.

## What to expect

You will get a reply when the report has been read. Confirmed problems are fixed as soon as possible
and announced in the release notes and on https://xami-sound.pages.dev.
